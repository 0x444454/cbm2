# SID player for CBM-II (B128/B256) 

Play SID tunes on your CBM-II computer.  
Currently supports B128/B256 only.  

## Floppy disk images

- **sidplayer.d64**: D64 image for 2031 and 4040 drives.  
- **sidplayer.d80**: D80 image for 8050, 8250 and SFD-1001 drives.  

## How to run

Insert disk and then type:

```
dload"sidplayer"
run
```

The disk contains 4 demo songs by Shiru (see below).  
Change disk after loading to play your favorite SID tunes (song list is not refreshed automatically, so load a song from the previous disk and when it fails, press "ENTER" to read the new disk).
