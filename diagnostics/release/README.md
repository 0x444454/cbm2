# BINARIES ARE HERE

Pick the binary for your target machine:

- **324735C.bin**      : CBM-II B-series Cartridge ROM (raw binary).
- **324735C.crt**      : CBM-II B-series Cartridge ROM (CRT format).

- **324735K.bin**      : CBM-II B-series Kernal replacement ROM (raw binary).
