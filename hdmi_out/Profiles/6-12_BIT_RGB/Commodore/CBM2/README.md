### Copy the .txt files in this "CBM2" folder into the "Commodore" folder of your RGBtoHDMI MicroSD card.

Example:


```
/Profiles/6-12_BIT_RGB/Commodore/CBM2/Default.txt
/Profiles/6-12_BIT_RGB/Commodore/CBM2/High-Profile.txt
```

### Colors

The default is white text on black background.  

Set ```output_colour=1``` for white text.  
Set ```output_colour=2``` for green text.  
Set ```output_colour=3``` for amber text.  
Set ```output_invert=0``` to swap text and background colors.
